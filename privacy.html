Privacy Policy

This policy covers Little Light Uploader, a private tool that uploads videos made by the Little Light channel to that channel on YouTube and to the owner's TikTok account.

Who uses it

Only the channel owner. The tool is not offered to other users.

What data it accesses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos with their title, description and tags to the owner's channel, and to read the status of those uploads. It does not access any other Google data.

TikTok

With the owner's permission (TikTok Login Kit), the tool uses the user.info.basic scope to identify the owner's account and the video.publish scope of the TikTok Content Posting API to post the owner's own videos, with their caption and privacy setting, to the owner's TikTok profile, and to read the status of those posts. It does not read followers, messages, or any other TikTok data. The owner can revoke access at any time in the TikTok app under Settings and privacy → Security → Manage app permissions.

Storage and sharing

The access token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. The owner can revoke Google access at any time at myaccount.google.com/permissions.

Google API Services

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Uploading to YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.
